This is a WiFi LED-matrix clock built from an ESP8266 (NodeMCU or Wemos D1 mini) and a MAX7219 8x32 LED module. It gets the time from the internet, and everything is set up from a phone. You don't edit any code, and no WiFi password goes into the firmware. It also updates itself from GitHub, so a clock you give away as a gift keeps getting new features.

The full source code is open source (MIT) on GitHub: github.com/ElectroIoT/ESP8266-Matrix-Clock. It works with both PlatformIO and the Arduino IDE.

Features

  • Internet time (NTP): India (IST) by default, 14 time zones to choose from, 12 or 24 hour
  • Set up from your phone: on first power-up the clock opens its own WiFi hotspot with a setup page
  • Settings web page: brightness, night mode, time format, animations, messages and more
  • 8 digit animations: roll down, roll up, dissolve, slide, flip, drop & bounce, random or instant
  • 5 effects: sparkle, wipe, rain, boxes and a Pac-Man-style chase, every hour and/or at power-on
  • Night mode: dims or switches the display off between hours you choose
  • Custom messages and special days: birthdays and anniversaries scroll with an animation all day, every year
  • Updates over WiFi: installs new GitHub releases by itself, over verified HTTPS
  • Safe mode: if an update ever crashes, the clock can still be fixed over WiFi
  • Optional password for the settings page
  • Any size: 4 to 16 modules (8x32 up to 8x128), and it can be mirrored or turned upside down
  • Optional light sensor for automatic brightness

What you need

Wiring

Step 1: Flash the firmware

Download the code from GitHub (green Code button → Download ZIP) and pick one of the two ways below.

Option A: Arduino IDE

  1. In File → Preferences → Additional boards manager URLs, add https://arduino.esp8266.com/stable/package_esp8266com_index.json
  2. Tools → Board → Boards Manager: install esp8266 by ESP8266 Community (version 3.x).
  3. Tools → Manage Libraries: install MD_MAX72XX by majicdesigns.
  4. Open arduino/MatrixClock/MatrixClock.ino. The other files open as tabs.
  5. Set Tools → Board to NodeMCU 1.0 (ESP-12E Module) (or LOLIN(WEMOS) D1 R2 & mini), Flash Size to 4MB (FS:2MB OTA:~1019KB) and CPU Frequency to 160 MHz.
  6. Plug in the board and press Upload.

Option B: PlatformIO (VS Code)

Open the project folder in VS Code with the PlatformIO extension and run:

pio run -e nodemcuv2 -t upload      # NodeMCU
pio run -e d1_mini   -t upload      # Wemos D1 mini

The MD_MAX72XX library is downloaded automatically.

Step 2: Connect it to WiFi from your phone

  1. Plug the clock in. It plays an animation, shows its welcome text and then scrolls "WiFi setup: join MatrixClock-XXXX then open 192.168.4.1".
  2. On your phone, join the WiFi network MatrixClock-XXXX. It has no password.
  3. The setup page opens by itself. If it doesn't, open http://192.168.4.1 in the browser. Tap your home network, type its password and press Save & connect.
  4. Done. The clock restarts, scrolls its IP address and shows the time. Switch your phone back to your home WiFi and open that IP address (or http://matrixclock.local) to reach the settings page.

If you typed the password wrong, the setup hotspot comes back, so just try again. If your router is only down for a while (for example after a power cut), the clock keeps trying your WiFi every 2 minutes.

Step 3: Make it yours on the settings page

FLASH button (NodeMCU): a short press scrolls the IP address. Hold it for 5 seconds to go back to WiFi setup, or for 10 seconds to remove a forgotten settings password.

Making it bigger: adding more modules

  1. Connect OUT of the last board (DOUT, CS, CLK) to IN of the next one (DIN, CS, CLK).
  2. On the settings page, under Display, set Modules to the new total. The clock restarts.
  3. Press Show module numbers: module 1 must be the one next to the ESP8266 wires.
  4. With 6 or more modules the clock also shows seconds.

Put a 470-1000 µF electrolytic capacitor (10 V or more) across 5 V and GND at each board's power input, + leg to 5 V. Connect all GNDs together.

Optional: automatic brightness

Connect an LDR (photoresistor) from 3V3 to A0, and a 10 kΩ resistor from A0 to GND. Then turn on Auto brightness on the settings page and choose the brightness for dark and for bright light. The page shows the live light level to help you choose. Night mode, when it's on, takes priority.

Updates and safe mode

With Automatic updates on (the default), the clock checks the latest GitHub release every night around 3 AM and a minute after power-on, and installs it if it's newer. Downloads use HTTPS with a verified certificate, and your settings and WiFi are kept. If a new version ever crashes 3 times in a row, the clock starts in safe mode. It keeps WiFi and the update page running and installs the next fixed release by itself.
